# Aluminum Calculator

تطبيق ويب لحساب مقاسات الألوميتال والشبابيك والأبواب بطريقة سريعة ودقيقة.

## ✨ المميزات

- حساب أبعاد قطاعات الألوميتال.
- تجميع مقاسات الشبابيك.
- حساب المساحات.
- حساب الأسعار النهائية.
- واجهة عربية سهلة الاستخدام.
- تصميم متجاوب مع الهاتف والكمبيوتر.

## 📦 تشغيل المشروع محليًا

```bash
git clone https://github.com/USERNAME/aluminum-calculator.git

cd aluminum-calculator

npm install

npm run dev
```
